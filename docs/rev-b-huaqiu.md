# Rev B 转华秋：询价与工程审核资料

2026-11-16。用户指定华秋 PCB + SMT，首批 3–5 套；先按 5 块 PCB、5 块贴装询价。本包用于询价、器件匹配和工程审核；没有工厂回签或订单号，不能作为已批准生产的记录。

## 上传文件与装配范围

- PCB 栏：`PCB-Gerber.zip`，只使用其中 Gerber 与 PTH/NPTH 制板，不混入旧版本。
- BOM 栏：`BOM-HuaQiu.csv`，相同料号合并为 35 行，共 93 个装配位号；数量为单板用量，不是五板总量，也不含采购备损。
- 坐标栏：`CPL-HuaQiu.csv`，93 行与 BOM 位号完全一致，单位 mm；底面 U5/R16/R17，其余顶面。
- 附件：本说明以及 `reference/assembly/orientation.html`、焊盘坐标、正反装配图。

其中 79 点为 78 SMT + 1 个 USB 混装；另外 14 点为 SW1–13 轴与 SW14 编码器，须另列 DIP/后焊费用。轴按客户寄料报价，暂未实际采购或寄出；不能误认为华秋已备齐。两颗 C19/C20 不贴，J1 铜箔引线由用户后装。USB 外壳四个镀槽必须焊牢，不能因未归入普通 SMT 而漏焊。35 种料包含后焊料，不擅自删减以符合优惠。

自动识别时把 MPN 对应“型号/规格”，Manufacturer 对应“品牌”，Footprint 对应“封装”，Designator 对应“位号”，Quantity 对应“单板用量”。保留指定 MPN；缺料转人工报价/寄料，不按阻值容量自动替代关键阻尼电阻、电容、MCU、麦克风和晶振。CPL 是 KiCad 原生角度，按参考编号图核对工厂库的实际旋转。

## 换厂必须复核的叠层

当前 Gerber/PCB 来自 JLC04161H-3313 设计：四层、1.6 mm，外铜 35 µm、内铜 15.2 µm，外层到 L2/L3 介质标称 0.0994 mm、Dk 4.1。**此编号仅说明原设计条件，不能当成华秋已提供同样叠层。** 华秋公开叠层和实际压合参数应由工程审核提供；若不同，先回传叠层及建议线宽/线距，完成复算、DRC 和新 Gerber 导出后再生产。

已在[华秋官方叠层页](https://www.hqpcb.com/quote/pressing)实际选择“四层 / 1.6 mm / 内铜 0.5 oz”：页面显示两侧 PP 为 7628、各 0.20 mm，芯板 1.1 mm H/H 含铜，外层成品 1 oz（表格 H/0.0175 mm 为起始铜箔），Dk 4.2。其外层介质明显不同于当前设计；网页截图与文本保存在 `build/huaqiu-review/stackup-four-layer.*`。本包必须先询问能否提供接近原设计的定制叠层；若不能，取得实际参数后再改 USB/RF 走线，不能将网页推荐线宽直接套到含共面地的现板。

必须选择“有阻抗”及“需要确认生产稿、不允许自动确认”。目标：顶层 USB 90 Ω 差分 ±10%（当前主段线宽 0.18 mm、边距 0.27 mm），RF 50 Ω 单端 ±10%（当前主段宽 0.16 mm、同层地间距约 0.22 mm），参考连续 L2 地。不得直接使用华秋默认叠层并沿用原阻抗结论。

其它参数：95×98 mm；绿阻焊、白字、ENIG；最细线 0.10 mm，局部间距规则 0.14 mm；最小过孔钻孔/铜径 0.20/0.40 mm；202 PTH、45 NPTH；USB 0.60 mm 镀槽。工艺边和定位点加在板外并回签拼板图。U1 九个 0.30 mm 散热孔优先填孔封帽；替代塞孔/钢网方案需工程审核。U1 锡膏 16 窗约 53% 覆盖，要求 QFN X-ray；U4 顶孔麦克风不能浸洗、超声清洗或堵孔。

## 活动与费用边界

官方 [PCB 领券中心](https://www.hqpcb.com/act/coupon.html) 的新客四层券抵扣上限为 200 元，需下单前领取；账号资格、领券与最终可抵扣金额需登录后核对。老客券另有常规工艺限制，本板有沉金和特殊工艺，不能套用“必定免费”的结论。

官方 [SMT 首单活动说明](https://www.hqpcb.com/help/p_1849.html) 对首单、数量和工艺有限制，不包含 BOM 元器件费、DIP 等费用，运费也可能另计。首单优惠是否适用于本板的双面贴装、35 种总物料、QFN X-ray 和指定孔工艺，应以账号资格及订单审核结果为准。普通钢网、无烧录/功能测试/整机组装可按需求选择；不为了优惠取消必要的 QFN 焊接检查或更换电源关键料。未获得报价前不承诺整单 0 元。
