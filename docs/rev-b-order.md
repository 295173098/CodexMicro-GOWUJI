# Rev B：3–5 套 PCB + 工厂贴装打样

本文件针对板载 ESP32-S3 的 **Rev B 四层板**。首批数量建议 5 块 PCB、3–5 块贴装；仅做工程验证，不视为量产或 USB/RF 合规认证。A4 双层文件不能混用。

设计侧已准备工程样机的制造与贴装资料。可用本包提交报价和 CAM 审核；**工厂确认下面的叠层/阻抗、QFN 工艺、齐料与贴装方向后才能开工**。尚无板厂接单记录、报价、CAM 回签或实物测试；文件准备不能替代这些确认。本仓库不会自动下单、付款或上传。

## 交厂文件

完整包：`build/rev-b-pcba.zip`。其中：

| 文件 | 用途 |
| --- | --- |
| `GOWUJI-RevB-PCB-Gerber.zip` | PCB 上传件：四铜层、双面阻焊/丝印/锡膏、板框、PTH 和 NPTH、Gerber job；不单独代表完整 PCBA 委托 |
| `assembly/BOM.csv` | 78 个 SMT + 1 个混装 USB 点位；按制造商料号采购，不允许按阻值/容量随意代换关键电源器件 |
| `assembly/CPL.csv` | 同一版主板的双面坐标，单位 mm；底面仅 U5、R16、R17 |
| `assembly/orientation.html` | 浏览器打开；极性器件的放大焊盘编号图，底面图按从底面观察显示 |
| `assembly/pad-coordinates.csv` | 与 CPL 同原点的焊盘坐标和网络；用于解决工厂库角度定义差异 |
| `assembly/secondary-assembly.csv` | 13 个 MX 轴 + 1 个编码器，单独报价后焊；不能遗漏 |
| `assembly/process.csv` | 全部 105 个 PCB 封装的装配分类；C19/C20 不贴；J1 触摸线后装；TP 与 H 不买元件 |
| `drawings/F-assembly.svg`、`B-assembly.svg` | 正反面总装配图；B 图为底面观察方向 |
| `validation/`、`manifest.json`、`SHA256SUMS.txt` | 当次 KiCad 检查、钻孔统计、输入版本哈希及交付文件校验 |
| `source/` | 本次导出所用 KiCad 源文件、器件目录和说明 |
| `firmware/GOWUJI-RevB-flash-0x0.bin` | Rev B 专用 4 MB 合并镜像，从地址 0x0 烧录；同目录含烧录脚本 |

BOM/CPL 使用[嘉立创要求的列名](https://jlcpcb.com/help/article/how-to-generate-the-bom-and-centroid-file-from-kicad)。料号不等于已锁库存；自动匹配失败时按 MPN 询价/代采或寄料。需要**双面、混装、寄料/代采可用的贴装服务**，不要直接套用基础单面贴装报价。若采购网站只接受商城编号，应按 MPN 匹配并核对封装，不能杜撰 C 编号。

CPL 保留 KiCad 角度，尚未在工厂器件库中逐件对齐；工厂必须按编号图确认，尤其 U1/U2/U3/U4/U5/U6、LED1–6、D1–19、J2/J3、X1、SW15。不要对全部器件统一加 90° 或盲目镜像坐标。LED 的外壳缺角对应 **3 脚 GND**；二极管色环对应 **1 脚 K**；U5 大散热片是 **2 脚 OUT**。晶振必须保持 1/3 为晶体端、2/4 接地，不能仅凭外壳倒角识别。

## PCB 下单参数

| 项目 | 指定值 |
| --- | --- |
| 数量/外形 | 5 块，95 × 98 mm，单板外形按 Edge.Cuts；禁止缩放 |
| 层数/厚度 | 4 层，1.6 mm，FR-4，指定 **JLC04161H-3313**，禁止替换为默认叠层或 3313A |
| 铜厚/表面 | 外铜 1 oz、内铜 0.5 oz，ENIG 沉金；绿阻焊、白丝印 |
| 层顺序 | F.Cu / In1.Cu（L2 地参考）/ In2.Cu / B.Cu |
| 最小线宽/间距 | 实板最细 0.10 mm；QFN 区局部线间距规则 0.14 mm，其余按项目规则。不是全板 0.14 mm 线宽 |
| 过孔 | 最小钻孔 0.20 mm、铜径 0.40 mm，径向环宽 0.10 mm；其余见钻孔报告 |
| 孔与槽 | 分离 PTH/NPTH；USB 四个外壳槽为 0.60 mm 成品镀槽，按 Excellon 路由槽加工，不能误做 NPTH |
| 检测 | 100% 电测；首批提供阻抗券/测试报告；PCBA 做 AOI，U1 做 X-ray |
| 机械 | 按 1.6 mm 板厚加工；不改安装孔、USB 位置或板框；工艺边/定位点由工厂加在板外并提交拼板图 |

官方 [JLC04161H-3313 叠层](https://jlcpcb.com/impedance)：顶/底铜 0.035 mm，外层至内层预浸料 0.0994 mm、Dk 4.1；内铜各 0.0152 mm、芯板 1.265 mm。加工能力参照[板厂工艺表](https://jlcpcb.com/capabilities/Capabilities)，最终仍由接单工厂确认该订单工艺。

USB 顶层主段：**90 Ω 差分 ±10%**，线宽 0.18 mm、直段边距 0.27 mm。RF_CHIP/RF_FEED 顶层主段：**50 Ω 单端 ±10%**，线宽 0.16 mm、相邻同层地常规间距约 0.22 mm。参考层均为连续 L2 地。二维设计模型约为 89.99 Ω/49.92 Ω；它不是板厂场求解器或实测。焊盘过渡、USB 插座并线和 RF 匹配器件不按均匀传输线计算。板厂若要求改线宽/间距，先反馈具体修改，不得直接移动器件或破坏地参考；修改后重跑 DRC 并重新导出。

## 必须写入 PCBA 委托的工艺

1. U1 为 0.4 mm 间距 QFN56，裸露焊盘 5.6 mm 方形。当前 16 个 1.04 mm 锡膏窗覆盖约 53%，避让 9 个 0.30 mm 散热孔。优先对这 9 孔采用**填孔并封帽**以避免吸锡；请厂方确认四层工艺及费用。若只能采用背面阻焊塞孔方案，先由 PCBA 工程师给出可接受的钢网/塞孔方案并回签，不得用普通开孔直接替代。首件 X-ray 确认桥连、吸锡与空洞。
2. 底面 U5/R16/R17 需双面工艺；工厂决定回流顺序及支撑方式。保留 U5 的铜散热区；不要为了贴装挖掉铜。首件装壳前测温。
3. U4 为顶孔麦克风，禁止浸洗、超声清洗、让助焊剂/胶/三防漆进入孔内；按 ST 器件回流限制处理。LED 按 Worldsemi 批次规格的防潮/回流要求处理。
4. J2 信号脚贴装，4 个外壳镀槽必须焊牢并检查；连接器位置决定外壳 USB 配合。不得自动换为相似的 12/24 脚 USB-C。
5. C19/C20 **DNP**。只装指定 2.2 nH 的 L1 作为起始 RF 匹配，量产前另测装壳射频。芯片必须是 FH4R2，不能换裸 S3 或不同内置存储器版本。
6. 13 个轴按客户提供的 **Gateron KS-9 红轴三脚版**配套后焊，SW4/SW13 必须相同批次；采购前核对所供轴的图纸。SW14 使用指定带按压编码器。没有寄轴时工厂仅完成 SMT/USB 部分，不能把缺轴的板称为完整整机。触摸铜箔、线、天线和外壳由用户装配，未计入 SMT 点位。

## 收板与复现

按 [首件上电](rev-b-bringup.md) 先验电源/USB，再做按键、麦克风和 BLE。首件热插拔、USB 枚举前/挂起电流、实际 LDO 温升、晶振与 RF 匹配均待测；不要仅凭 ERC/DRC 或 ngspice 结果量产。

用装有 KiCad 9 `pcbnew` 模块及 `gerbonara` 的 Python 3，先按元件审核说明生成仿真证据、导出网表并编译固件：

```sh
python3 tools/export_rev_b_order.py --kicad-cli kicad-cli --out build/rev-b-pcba \
  --evidence build/rev-b-order \
  --firmware build/firmware-rev-b/Gowuji.ino.merged.bin
```

脚本拒绝混入旧目录，检查 ERC/DRC/原理图一致性、BOM/坐标/DNP 一致性、叠层及输入哈希；独立解析 Gerber 四铜层、外形和钻孔数量，再生成完整 ZIP 与单独 Gerber ZIP。输入修改后必须导出到新目录。电源复现命令见元件审核说明；固件用 `python3 tools/build_firmware.py --rev-b --install` 编译，不要烧录 Rev A 镜像。`--evidence` 中还需保留本次村田偏压数据及请求 URL；可从本包 `validation/evidence/` 取回原始证据，重新仿真后使用，不能把旧仿真当成新设计结果。
