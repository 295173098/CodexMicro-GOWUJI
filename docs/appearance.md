# Rev A4 外观选件

参考照片重做可见外观；按键位置、PCB、固件、安装柱、拾音孔和触摸铜箔沿用 A4。照片不能确认原厂的尺寸、公差、底盘功能和材料，因此这是可打印的参考造型。

- 正面：圆角外壳、微凸边框和内嵌面板、浅凹键帽、圆形触摸标记、低一些的可拆 USB 盖。外壳底边比基础 A4 多 1.8 mm，为最后一排键让出行程。六颗状态键用半透明材料，白色指令键用不透光材料。标记槽可填对比色；图里的触摸圆点可用非金属薄贴实现。
- 背面：底壳边沿做浅描边，中央是直径 76 mm 的装饰圆盘，带外圈、浅盘面和约 0.65 mm 深的凹刻标志。圆盘单独打印，再用薄双面胶贴进底壳定位圆槽。
- 沿用 A4 底下的导光件、摇杆帽和泡棉密封环。面板外侧朝床打印时，内凹区域会高出打印床 0.9 mm，建议按切片预览对面板下方开启可拆支撑，或用适合机型的面板朝上加支撑。键帽建议先印一颗试配 MX 轴，再选打印方向和支撑；清理十字孔和拾音孔的毛刺。圆盘平面朝床，图案朝上。

模型验证覆盖 4 mm 键程、拾音孔通畅、USB 插头包络、圆盘定位和 STL 网格闭合。透光效果、打印公差、键帽手感和录音还需在样机上测。

```powershell
python mechanical/appearance.py
python tools/review_appearance.py --kicad-cli .local/kicad/bin/kicad-cli.exe
```

生成到 `build/appearance/`。在 KiCad PCB 编辑器打开 `appearance-preview.kicad_pcb` 后按 `Alt+3`。该文件只用于看外观；生产使用 Rev A4 的 KiCad 原文件和 Gerber。
