# Rev B 制造审阅单

本单供核对工程样机工艺。完成阻抗和贴装审核后，再从同一版 KiCad 主板重新生成下单文件。

| 项目 | 提供给板厂的参数 |
| --- | --- |
| 尺寸与叠层 | 95 × 98 mm 板框中心线，1.6 mm 四层 FR-4；JLC04161H-3313，外铜 1 oz、内铜 0.5 oz，ENIG |
| 参考地 | L2（In1.Cu），禁止为工艺优化在信号主段下方开槽或挖空 |
| USB | F.Cu 的 USB_P/USB_N 干线，90 Ω 差分 ±10%；线宽 0.18 mm、直线边距 0.27 mm、主要斜线边距约 0.266 mm；短焊盘过渡、插座并线不按均匀传输线计算 |
| 射频 | F.Cu 的 RF_FEED 和 RF_CHIP 干线，50 Ω 单端 ±10%；线宽 0.16 mm，同层地的最小常规间距约 0.22 mm；只对主段做阻抗控制，保留 U.FL 与匹配器件过渡 |
| 钻孔 | PTH/NPTH 分开；局部 15 个 0.20 mm 钻孔，焊环外径 0.40 mm；选择支持该组合的工艺选项。USB 外壳四个 0.60 mm 成品镀槽，按 PTH 钻孔的铣槽输出加工 |
| 阻抗验收 | 提交叠层确认、建议成品线宽/间距及阻抗公差。若需改铜须先核对 DRC，保留连接器、ESP32 与匹配器件的细线过渡；首批索要阻抗测试券或报告 |

以下分开审核贴装：板顶 U1 的裸露焊盘钢网和 Pin 1，U4 顶部拾音孔禁止清洗液与涂覆，J2 信号脚回流/外壳镀槽焊接方式；板底 U5、R16、R17 的料号与方向。C19/C20 预留，默认不贴。MX 轴、编码器及摇杆是否由工厂焊接应在报价时单独确认。

U1 使用本地 `Gowuji:S3` 封装。保留原铜焊盘和九个 0.30 mm 散热过孔，16 个锡膏窗改成 1.04 × 1.04 mm 圆角矩形，覆盖裸露焊盘约 53%。标称孔边至最近锡膏窗约 0.13 mm。实际钢网对位及锡膏流动仍由贴装厂评估，必要时按厂方审核要求填孔。

`positions/process.csv` 列出工艺分组；`smt-review.csv` 供纯 SMT 贴装审核，包含贴装摇杆 SW15，不含混装 J2、手焊轴和编码器、触摸线及测试焊盘。底面旋转仍按 KiCad 导出值，需用板厂预览核对。

本地导出：

```powershell
./tools/export_rev_b_review.ps1 -KiCadCli .local/kicad/bin/kicad-cli.exe
```
